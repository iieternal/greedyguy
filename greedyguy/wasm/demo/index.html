🧩 Context Models

Multiple models of varying order (0–12) track byte sequences of different lengths. Specialized models for HTML structure, English words, and repeated byte matches provide additional predictions.

🔀 Neural Mixer

A logistic neural network combines predictions from all context models, weighting each by recent accuracy. This "mixture of experts" approach achieves better predictions than any single model.

📊 APM Cascade

Adaptive Probability Maps further refine the mixed prediction through a chain of context-dependent lookup tables, correcting systematic biases in the mixer output.

🔢 Arithmetic Coder

The final probability is fed to a binary arithmetic coder that encodes each bit using near-optimal code lengths — approaching the theoretical entropy limit for the predicted distribution.
